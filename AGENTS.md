# Milu project workflow

This is a Windows-only Electron + React + TypeScript secretary MVP.

The user wants to continue development from multiple PCs using GitHub. After completing authorized code changes, commit and push this project's source and documentation to its configured GitHub repository. Verify the remote commit before reporting success. Do not force-push or upload runtime task data, credentials, dependency folders, or build caches. If the destination is missing or inaccessible, report that clearly and retain the local work.

Read README.md and VALIDATION.md for setup and known verification limits. Run npm test and npm run build when relevant code changes. Windows login startup and actual speech output need separate installed-app verification.
