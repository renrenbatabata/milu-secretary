# Milu — Windows AI秘書 MVP

水色と白のキャラクターと、親しみやすい相棒の話し方を備える Electron + React + TypeScript アプリです。現在はローカルの秘書MVPで、LLM・カレンダー・天気・金融サービスには接続していません。ブリーフィングには「デモ」と表示し、現在の情報ではないことを音声でも伝えます。

## Windowsで起動

Windows 10/11 x64、Node.js 22.12以降または24 LTSを使用してください。PowerShellでこのフォルダーに移動します。

```powershell
npm install
npm test
npm start
```

Electron本体の取得に失敗した場合は、ネット接続を確認して `npm rebuild electron` を実行してから再起動してください。

依存パッケージ取得は初回のみインターネットが必要です。`npm start` はTypeScriptの検査と本番ファイルの生成後、Electronを起動します。ブラウザーだけで開く運用は対象外です。開発版ではWindowsの自動起動を登録しません。

## インストーラーを作る

```powershell
npm run package
```

`release` に生成される `Milu Setup 0.1.0.exe` をインストールします。初回起動で「自動起動を有効にして始める」または「自動起動なしで始める」を選択してください。後から「Miluの設定」で切り替えられます。Windows側の「スタートアップ」で無効にした場合も、画面では実際の登録状態を取得します。自動起動は `app.setLoginItemSettings` で、インストール先の実行ファイルに `--login-start` を渡して登録します。読み取りも同じpath/argsを使用します。

インストーラー作成にはElectronやWindows向けビルド資材のダウンロードが必要です。配布署名は未設定のため、Windowsで警告が出る場合があります。

## 挨拶と音声

- 初回の選択を終えた後、起動時のPCローカル時間が6:00〜11:59なら朝の挨拶を自動読み上げします。手動起動も対象です。
- 12:00〜翌5:59の起動では自動読み上げしません。夜間起動後に朝まで開いていても、タイマーで読み上げることはありません。
- 同日1回の制御はメインプロセスで行い、再生前に日付を保存します。多重起動も拒否します。保存後のクラッシュや音声失敗では、その日は自動再試行しません。重複防止を優先した仕様です。
- ミュート・挨拶OFF・日本語のローカル音声がない場合、朝の再生日は消費しません。設定を変更した場合、次の起動から自動挨拶を適用します。
- 「自動起動OFF」はWindowsログイン時の起動だけを止めます。「朝の挨拶OFF」は自動挨拶を止めます。「音声をミュート」は手動を含む全読み上げを止め、再生中の音声も停止します。
- ブリーフィングと試聴は利用者が押した時だけ読み上げるため、夜間でも利用できます。
- 音声はWindowsの日本語ローカル音声だけを使用し、速度0.9・ピッチ1.0で読み上げます。中性的な印象を保証する専用モデルは未搭載です。設定でインストール済みの声を選んで試聴してください。
- 音声がない場合、Windowsの「設定」→「時刻と言語」→「音声認識」などから日本語音声を追加してください。追加時にはネット接続が必要です。表示される音声はWindowsとElectronの対応に依存します。

## 保存とオフライン

画面・キャラクター・モックデータはすべて同梱し、ネット接続なしで起動できます。タスクと設定と再生日はElectronの `userData` 内の `milu.json` に保存します（通常 `%APPDATA%\Milu\milu.json`）。一時ファイルから置き換えて保存し、保存エラーを画面に表示します。JSON破損時は元データを保護して起動を停止します。バックアップ後に修復するか、ファイル名を変更して初期化してください。保存内容は暗号化していません。

## 自動テスト・Windows実機確認

`npm test` は朝の時間境界、同日重複と翌日、ミュート、挨拶OFF、初期OFF、設定検証、ファイル保存・保存失敗・破損保護を検証します。`npm run build` はElectronとReactのTypeScript検査および画面の本番ビルドを実施します。

インストール版では次の実機確認を行ってください。

1. 初回に自動起動なしを選ぶ。Windowsのスタートアップに有効なMiluがないことを確認。
2. 設定で自動起動をONにする。WindowsのスタートアップにMiluが登録されることを確認し、サインアウト→ログインで自動起動することを確認。
3. 朝に挨拶を聴き、終了→再起動して同日は再生しないことを確認。翌朝は1回再生することを確認。
4. 夜間のログインで読み上げしないことを確認。時間変更で試す場合はVMなどを利用し、確認後に時刻を戻す。
5. ミュートと挨拶OFFをそれぞれ確認。読み上げ中のミュートで停止することを確認。
6. 自動起動OFFにしてサインアウト→ログインし、起動しないことを確認。
7. タスクを追加・完了・削除し、終了→再起動で状態が維持されることを確認。
8. ネットを切断してインストール版を起動し、画面・タスク・ローカル音声が利用できることを確認。
9. 日本語音声のない環境で起動し、画面操作は可能で音声の案内が出ることを確認。

実際のログイン、スピーカー出力、署名付き配布の確認は自動テストとは別に必要です。

## 構成

- `electron/main.ts`: Windows自動起動、単一起動、IPC、挨拶の予約
- `electron/store.ts`: ローカルの永続保存
- `electron/domain.ts`: 時間帯・同日制御・設定検証
- `electron/preload.ts`: 操作を限定した画面向けAPI
- `src/main.tsx`: ダッシュボード、タスク、初回選択、設定、ローカル読み上げ

ElectronはcontextIsolation・sandboxを有効、nodeIntegrationを無効にし、IPC送信元を確認します。外部ページの遷移と新規ウィンドウを拒否し、画面からのネット接続をCSPで禁止します。

実装参照: [Electronの自動起動API](https://www.electronjs.org/docs/latest/api/app)、[Context Isolation](https://www.electronjs.org/docs/latest/tutorial/context-isolation)。
